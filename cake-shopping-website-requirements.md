# Build a Cake Shopping Website

Design and build a visually appealing, fully functional, multi-page cake shopping website using **Next.js**, **TypeScript**, and **Tailwind CSS**.

## Requirements

- Maintain the layout of the provided **registration page** reference. Improve its visual polish without changing the core structure.
- Write all interface text, labels, messages, and code comments in **English**.
- Use the [Lightswind](https://lightswind.com/) component library, especially its **Liquid Glass** components for alerts, avatar/glass cards, and checkboxes.
- Follow the existing project's component patterns and architecture. Build the interface from reusable, component-based modules.
- Do **not** hard-code product data, repeated content, form options, routes, or UI values inside components. Store reusable data in typed constants or configuration files and render it dynamically.
- Add simple registration-form validation with clear inline English error messages.
- Do not use `localStorage`, `sessionStorage`, cookies, or similar browser storage for registration data or application state.
- Keep validation and state handling simple and in memory. No backend or persistent storage is required unless the existing project already provides one.
- Prioritize responsive design, accessibility, user experience, and a cohesive visual style across all pages.
- Use the provided sample image as the primary reference for the registration-page layout, while making meaningful improvements to spacing, hierarchy, responsiveness, and overall visual appeal.
